# 📥 Как скачать приложение

## Способ 1: Скачать собранные файлы (самый простой)

1. Скачайте папку `dist/` с собранными файлами
2. Откройте `dist/index.html` в любом браузере
3. Готово! Приложение работает локально без сервера

**Что внутри:**
- `index.html` - главная страница
- `assets/index-*.js` - JavaScript код (153 KB)
- `assets/index-*.css` - стили (22 KB)

## Способ 2: Установить как PWA (рекомендуется)

Если приложение открыто в браузере:

### Chrome/Edge:
1. Посмотрите на адресную строку
2. Нажмите на иконку "Установить" (⊕ или 📥)
3. Подтвердите установку
4. Приложение появится в меню Пуск/программ

### Safari (macOS/iOS):
1. Нажмите кнопку "Поделиться" (⎙)
2. Выберите "На экран Домашний"
3. Подтвердите

## Способ 3: Скачать исходный код

Если вы разработчик и хотите изменить код:

```bash
# Клонировать репозиторий
git clone <url>

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать для продакшена
npm run build
```

## Способ 4: Запустить через локальный сервер

Если хотите открыть через сервер:

```bash
# Вариант 1: Через Node.js
npx serve dist

# Вариант 2: Через Python 3
cd dist && python -m http.server 8000

# Вариант 3: Через PHP
cd dist && php -S localhost:8000
```

Затем откройте http://localhost:8000 (или другой порт)

## 📱 Мобильные устройства

### Android:
1. Откройте сайт в Chrome
2. Нажмите меню (⋮)
3. Выберите "Добавить на главный экран"
4. Приложение установится как PWA

### iOS:
1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться" (⎙)
3. Выберите "На экран Домашний"
4. Подтвердите установку

## 🎯 Что выбрать?

- **Просто послушать радио** → Способ 1 (открыть index.html)
- **Использовать как приложение** → Способ 2 (установить PWA)
- **Изменить код** → Способ 3 (скачать исходники)
- **Тестировать локально** → Способ 4 (запустить сервер)

## ❓ Проблемы?

Если приложение не работает:
1. Проверьте интернет-соединение (нужно для загрузки станций)
2. Попробуйте другой браузер (Chrome/Edge/Firefox)
3. Очистите кэш браузера (Ctrl+Shift+Del)
4. Проверьте консоль браузера (F12) на ошибки
