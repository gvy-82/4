# 🎵 Russian Radio - Онлайн Радио

Минималистичное веб-приложение для прослушивания российских радиостанций.

## 🚀 Как использовать

### Вариант 1: Открыть локально
1. Распакуйте архив
2. Откройте файл `dist/index.html` в браузере
3. Готово! Приложение работает без сервера

### Вариант 2: Установить как PWA (рекомендуется)
1. Откройте сайт в Chrome/Edge
2. Нажмите на иконку установки в адресной строке
3. Приложение установится как десктопное

### Вариант 3: Запустить через сервер
```bash
# Если у вас есть Node.js
npx serve dist

# Или через Python
cd dist && python -m http.server 8000
```

## ✨ Возможности

- 📻 Список российских радиостанций
- 🔍 Поиск по названию и жанрам
- ▶️ Воспроизведение в один клик
- 🎚️ Регулировка громкости
- 📱 Адаптивный дизайн
- 🌙 Тёмная тема

## 🛠️ Технологии

- React 18
- TypeScript
- Tailwind CSS v4
- Vite
- Radio Browser API

## 📦 Структура

```

```
